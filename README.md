# gridlings-legal

Draft About, Privacy Policy and Terms of Use pages for the Gridlings Android game, built for GitHub Pages.
Prepared 23 October 2026. These are **review-ready drafts**: they are not legally reviewed or approved.

## Before publishing
1. Remove the yellow "Draft for review" notice and the "(draft)" footer label from `privacy-policy.html` and `terms.html`.
2. Remove `<meta name="robots" content="noindex">` from those two pages.
3. If you publish on a later date, change the "Effective date" on both pages.

## Files
- `index.html` – landing page linking the three pages
- `about.html`, `privacy-policy.html`, `terms.html`
- `style.css` – shared styles
- `assets/gridlings-icon.png` – the app's launcher icon
- `.nojekyll` – tells GitHub Pages to serve the files as they are

All links are relative, so the site works at `https://YOUR-GITHUB-USERNAME.github.io/gridlings-legal/`.
